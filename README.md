Student Notes App

A simple note browsing application designed for students of Grade 11, 12, and Bachelor level to view and access study notes easily.

Features
View and browse available notes
Organized notes for Grade 11, 12, and Bachelor level
Simple and clean user interface
Fast and lightweight design
Easy navigation between subjects and topics


Tech Stack
Backend: Django (Python)
Frontend: HTML, CSS, JavaScript

Note

This is a demo project with pre-added notes only. Users can browse existing content but cannot create or upload new notes.
